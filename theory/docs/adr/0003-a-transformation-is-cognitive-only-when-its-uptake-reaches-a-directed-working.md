# A transformation is cognitive only when its uptake reaches a working that a criterion directs

ADR 0001 defined a cognitive transformation by uptake alone: something takes the output up and transforms it, anywhere, under no criterion. That made "cognitive" coextensive with "a non-terminal link in a stated chain": a JPEG pipeline alone and the weather (`weather_is_not_cognitive`) came out as organised cognitive systems, and nothing in the Core could refuse them. The vault ties "cognitive" to a role in a system working under task criteria, goals or value gradients; 0001's arguments hit the vault's modal "can" and its presupposition of the larger system, not the criterion-relativity, and the fix over-corrected. The Core now requires the taker to be a component of a directed system (`cognitive_when_taken_up_into_a_directed_working`), and serving as a mechanism in a system requires that system directed (`mechanism_when_its_output_is_taken_up_in_a_directed_system`). `cognitive_system`, `realises_intelligence` and `nested_in` inherit direction unchanged; the composition Claims stay criterion-free, so "transforms as a system" remains derivable (`turns/3`) without the cognitive name. A recurrent system stays structural, and a recurrent cognitive system is one that is also a cognitive system (`recurrent_cognitive_when_directed`); only that can revise. Decided in issue #16, at the rendering gate.

## Considered options

- Keep the uptake-only Claim under a new name and add the directed one on top. Rejected: it keeps, under a new name, exactly the layer judged not cognitive, and renamed phenomena would test nothing about cognition.
- Require the chain of uptake to reach the component that takes the criterion up. Rejected for now: one step into a directed system is Horn-simple and already refuses every undirected case; the stricter form can be added if a phenomenon needs it.
- Require direction of the transforming side too. Rejected: the vault lets a mechanism belong to no system (the translator, the author read a century later, the last move before action), and 0001's answers to those objections survive by drawing the taker's boundary (the client's firm, the reader's scholarship, the game that includes the world).
- Make recurrence require direction. Rejected: the vault defines recurrence as temporal re-entry, structural; the directed case gets its own Claim instead.

## Consequences

- A system that merely transforms as a system is not cognitive (`pipeline_alone`, `coupled_but_undirected`); a criterion that is only attributed still directs nothing (`pipeline_with_an_attributed_criterion`).
- Intelligence does not descend: a mechanism in an intelligent system need not be intelligent at its own boundary, and nesting requires the inner system directed at its own scale (`pipeline_as_mechanism_in_a_larger_system` refuses `nested`, `pipeline_with_a_comparator` expects intelligence).
- Mechanism-hood is boundary-relative and extends to whatever a directed system takes up and transforms, the environment included, when the phenomenon author draws the boundary so. The theory refuses cognition without direction; it does not judge the facts.
- The vault's "context-sensitive" qualifier, which 0001 dropped without recording it, stays out: the Core has no predicate for it, and direction now does the excluding work the qualifier did informally. Tracked in issue #5 with the other unformalised passages.
- Phenomena that expect a cognitive observation must state a criterion and the component that takes it up; seventeen of slice 1's were rewritten so.
